# Security Policy

## Supported Versions

This project is currently in active development. Security fixes are expected to target the `main` branch unless a release branch policy is introduced later.

| Version | Supported |
| --- | --- |
| `main` | Yes |

## Reporting a Vulnerability

Please do not disclose security vulnerabilities publicly in GitHub issues.

If you discover a vulnerability, report it privately to the maintainer:

- GitHub: [Shreyas-R-Gowda](https://github.com/Shreyas-R-Gowda)

If a private security advisory is available for the repository, use GitHub's private vulnerability reporting flow. Otherwise, contact the maintainer directly and include enough detail to reproduce or assess the issue.

## What to Include

Please include:

- A clear description of the vulnerability.
- Affected component: frontend, backend, database, deployment, AI/ML, or documentation.
- Steps to reproduce.
- Impact and severity estimate.
- Any proof-of-concept code, screenshots, logs, or request examples.
- Suggested remediation, if known.

## Security Areas of Interest

Reports are especially welcome for:

- Authentication or authorization bypass.
- Token/session leakage.
- Unsafe file upload behavior.
- SQL injection or unsafe query construction.
- Cross-site scripting or frontend injection.
- Sensitive data exposure.
- Secrets committed to the repository.
- Rate-limit bypass or denial-of-service vectors.
- AI endpoint abuse or cost-exhaustion paths.
- Misconfigured CORS or deployment settings.

## Response Expectations

Maintainers will aim to:

1. Acknowledge receipt of the report.
2. Triage severity and reproducibility.
3. Develop or request a fix.
4. Credit the reporter when appropriate and desired.

This is a student/MVP-stage project, so response times may vary. Please act responsibly and avoid exploiting vulnerabilities beyond what is needed to demonstrate impact.

## Safe Harbor

Good-faith research is welcome when it:

- Avoids privacy violations.
- Avoids data destruction or service disruption.
- Does not access or modify other users' data.
- Is reported promptly and privately.

Activities outside these boundaries may not be considered authorized.
